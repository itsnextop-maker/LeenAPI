LeenAPI gives your app chat, images and voice with one key. Buy a key on the pricing page, then send requests like the ones below.

The basics

  • Base address: https://leenapi.onrender.com
  • Send your key in the header x-api-key.
  • Send and receive JSON.
EndpointWhat it does
POST /chatSend messages (and an optional system text that gives the AI a role), get a reply
POST /imageSend a prompt, get image_base64
POST /voice/speakSend text and lang, get audio_base64
POST /voice/agentUpload audio, get the answer as text and audio
GET /meSee your daily usage

JavaScript

const res = await fetch("https://leenapi.onrender.com/chat", {
  method: "POST",
  headers: { "x-api-key": "leen_your_key", "Content-Type": "application/json" },
  body: JSON.stringify({ messages: [{ role: "user", content: "Hello" }] })
});
const data = await res.json();
console.log(data.reply);

Python

import requests, base64

H = {"x-api-key": "leen_your_key"}
U = "https://leenapi.onrender.com"

r = requests.post(U + "/chat", headers=H,
    json={"messages": [{"role": "user", "content": "Hello"}]})
print(r.json()["reply"])

r = requests.post(U + "/image", headers=H, json={"prompt": "a red apple"})
open("apple.jpg", "wb").write(base64.b64decode(r.json()["image_base64"]))

curl

curl -X POST https://leenapi.onrender.com/chat \
  -H "x-api-key: leen_your_key" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Hello"}]}'

If something goes wrong

401The key is missing or wrong.
403The key was switched off. Contact the owner.
429Daily limit reached. It resets at midnight Bangladesh time.
502An outside service is busy. Wait a moment and try again.

Keep your key safe

Anyone who can read your page's code can copy a key placed inside it. For a public website, send requests from your own server, and keep the key there.
